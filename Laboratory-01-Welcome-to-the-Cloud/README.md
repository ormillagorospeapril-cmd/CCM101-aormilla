# Laboratory 01 — Welcome to the Cloud

## 🎯 Mission Overview
This mission introduces the cloud environment, Linux command line interface, and professional documentation practices using GitHub. I prepared a cloud-based workspace on KillerCoda and created a portfolio repository to store all my work throughout the semester.

## 📋 Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub portfolio repository
- Document technical work using Markdown

## ✅ Activities Performed
1. Launched Ubuntu 24.04 playground on KillerCoda and verified terminal functionality
2. Created new user `aormilla` with Bash shell, home directory, and sudo privileges
3. Retrieved system details including OS version, kernel, CPU, memory, and disk space
4. Built organized workspace folder structure and created introduction document
5. Created GitHub portfolio repository: CCM101-aormilla
6. Wrote all required documentation using Markdown and prepared evidence screenshots
