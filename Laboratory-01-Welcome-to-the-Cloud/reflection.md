# Reflection — Laboratory 01

Completing this laboratory activity gave me a clear understanding of what cloud engineers do on a daily basis. I learned that Linux is the foundation of cloud computing and that knowing how to use the command line is an essential skill. Creating my own portfolio repository on GitHub showed me the importance of keeping work organized and properly documented.

I found creating files and folders and writing Markdown documentation to be straightforward. The most challenging part was remembering the exact syntax of some Linux commands, especially when creating the new user account. However, by following the steps carefully and practicing repeatedly, I was able to complete each task successfully.

This activity taught me that technical skills are equally important with good documentation. A well-organized portfolio not only helps track my progress but also demonstrates my skills professionally. Moving forward, I am excited to learn more cloud technologies and continue building this portfolio throughout the semester.
