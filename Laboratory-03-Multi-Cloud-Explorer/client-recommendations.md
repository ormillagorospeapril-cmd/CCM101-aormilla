# Client Recommendations

---

## Client A — Startup Company → Recommend: AWS
AWS is the best choice because it supports rapid growth while offering a generous Free Tier and pay-as-you-go pricing that fits limited budgets. It provides room to scale without rebuilding infrastructure later. Key services: **Amazon EC2** for app servers, **Amazon S3** for media storage, and **Amazon RDS** for databases.

---

## Client B — University → Recommend: Azure
Azure naturally extends the university's existing Microsoft investments. Windows Server, Microsoft 365, and Active Directory all integrate natively without costly changes or migration complexity. Key services: **Azure Virtual Machines**, **Entra ID**, and **Azure Backup**.

---

## Client C — AI Research Company → Recommend: GCP
GCP is the clear leader in AI, machine learning, and high-performance computing — built on Google's own research infrastructure. It provides ready-to-use AI tools and supports powerful GPU/TPU clusters. Key services: **Vertex AI**, **Compute Engine (GPU instances)**, and **Cloud Storage**.

---

## Client D — Global E-Commerce Company → Recommend: AWS
AWS has the largest global infrastructure footprint and proven reliability. It offers auto-scaling across multiple zones to handle worldwide traffic spikes. Key services: **EC2 Auto Scaling**, **Amazon S3 + CloudFront (CDN)**, and **Elastic Load Balancing**.

---

## Multi-Cloud Decision Matrix (Checkpoint 6)

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Free Tier, flexible pricing, broad services, strong community support |
| Enterprise Organization | AWS | Most mature, wide compliance certifications, huge partner ecosystem |
| Microsoft Environment | Azure | Built-in compatibility with Windows, Active Directory, 365, and .NET |
| AI / Machine Learning | GCP | Leader in AI/ML tools, TensorFlow support, easy GPU/TPU access |
| Kubernetes Deployment | GCP | Created Kubernetes; GKE is the most mature and standard implementation |
| Global Web Application | AWS | Most Regions & Availability Zones, proven reliability, auto-scaling, global CDN reach |
