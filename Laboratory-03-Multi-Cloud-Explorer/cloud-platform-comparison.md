## Comparison Questions

### 1. Which cloud provider offers the broadest range of services?
AWS offers the widest selection — hundreds of services across every category. Being the oldest provider, it has mature offerings in compute, storage, databases, analytics, security, and emerging technologies that cover nearly every business use case.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure is purpose-built for Microsoft environments. It connects natively with Windows Server, Active Directory, Microsoft 365, .NET, and Visual Studio — making migration and integration smooth and cost-effective for existing Microsoft customers.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform leads in both areas. Google created Kubernetes, offers industry-leading AI APIs, and provides advanced machine learning tools built on the same technology used inside Google.

### 4. Which cloud platform would you personally choose and why?
I would choose AWS for most general enterprise needs because of its maturity, global reach, and vast service options. However, for AI-focused or cloud-native projects, I would choose GCP for its innovation, open culture, and Kubernetes leadership.
